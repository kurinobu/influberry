## 3. タブ切り替えの問題の分析

### 3.1 問題の詳細

コンソールログより、以下の問題が確認されました:

1. **タブが複数回切り替わる問題**:
   ```
   🔧 Phase 2: currentMonthTabの変更を検知 {newTab: '2025-11', oldTab: 'overview'}
   🔧 Phase 2: currentMonthTabの変更を検知 {newTab: '2025-10', oldTab: '2025-11'}
   🔧 Phase 2: currentMonthTabの変更を検知 {newTab: '2025-11', oldTab: '2025-10'}
   ```

2. **lastRotationCheckが古い**:
   - `lastRotationCheck: '2025-10-01T00:00:00'`（10月1日）
   - 現在は11月1日だが、`lastRotationCheck`が10月1日のまま

3. **現在日時とlastRotationCheckの不一致**:
   ```
   ⚠️ 現在日時とlastRotationCheckが不一致 - 現在月を優先
   {currentMonthId: '2025-11', lastMonthId: '2025-10'}
   ```

### 3.2 根本原因の分析

**原因1: データベース状態の問題**
- ローカル環境のデータベースで、11月の月次切り替えが実行されていない
- `lastRotationCheck`が10月1日のまま更新されていない

**原因2: タブ切り替えロジックの競合**
- 初期化時に`2025-11`タブが選択される
- その後、`lastRotationCheck`に基づいて`2025-10`タブに戻る
- 再度、現在日時チェックにより`2025-11`タブに戻る
