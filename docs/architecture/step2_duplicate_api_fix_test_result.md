## 3. 重複API呼び出しの分析

### 3.1 現在の状況

**ログ確認**:
```
overview-minimal	200	xhr	monthly.js:461	0.4 kB	11 ms
overview-minimal	200	xhr	monthly.js:461	0.4 kB	32 ms
```

**分析**:
- `overview-minimal`が2回呼び出されている（11ms, 32ms）
- ログでは「🔧 キャッシュがないため、fetchOverviewMinimal()を呼び出し（フォールバック）」が出力されている
- これは`nextTick()`のタイミングの問題で、キャッシュが設定される前にチェックされている可能性がある

**評価**: ⚠️ **部分的な改善** - 重複呼び出しは削減されているが、完全には削減されていない

---

### 3.2 改善前後の比較

**改善前**:
- `overview-minimal`: 2回（25ms, 35ms）

**改善後**:
- `overview-minimal`: 2回（11ms, 32ms）

**改善量**:
- 応答時間: 60ms → 43ms（約28%改善）
- 呼び出し回数: 2回 → 2回（変更なし）

**評価**: ⚠️ **部分的な改善** - 応答時間は改善されたが、呼び出し回数はまだ削減されていない

---

### 3.3 原因分析

**可能性1: `nextTick()`のタイミング問題**

**問題点**:
- `DashboardPage.vue`での`fetchOverviewMinimal()`呼び出しが完了する前に、`MonthlyStatsSection.vue`の`loadData()`が実行されている可能性がある
- `nextTick()`だけでは、非同期API呼び出しの完了を待つことができない

**解決策の検討**:
- `nextTick()`の代わりに、`Promise`を使用して`fetchOverviewMinimal()`の完了を待つ
- または、`monthlyStore`に`fetchingOverviewMinimal`フラグを追加し、取得中は待機する

**評価**: ⚠️ **タイミング問題** - `nextTick()`だけでは不十分な可能性がある

---

**可能性2: 初期化タイミングの競合**

**問題点**:
- `DashboardPage.vue`の`onMounted()`と`MonthlyStatsSection.vue`の`onMounted()`が同時に実行されている
- `DashboardPage.vue`での`fetchOverviewMinimal()`呼び出しと、`MonthlyStatsSection.vue`での`loadData()`呼び出しが競合している可能性がある

**解決策の検討**:
- `DashboardPage.vue`での`fetchOverviewMinimal()`呼び出しを`await`で確実に完了させた後に、`MonthlyStatsSection.vue`をマウントする
- または、`MonthlyStatsSection.vue`の`onMounted()`で`loadData()`を呼び出す代わりに、`watch`のみに依存する

**評価**: ⚠️ **タイミング問題** - 初期化タイミングの競合の可能性がある
