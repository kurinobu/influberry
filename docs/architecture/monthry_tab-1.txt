
# 📋 **月次切り替え機能の根本原因調査レポート**

## 📊 **調査概要**

- **調査日時**: 2025年10月24日
- **報告者**: AI Assistant
- **調査対象**: 月次切り替え後にタブが視覚的に切り替わらない問題

---

## 🎯 **問題の定義**

### **理想とする状態**
```
11月1日0時0分の自動切り替え後
- タブ表示: 「概要」「9月」「10月」「11月」
- 選択タブ: 「11月」（ピンク色のボーダー）
- ユーザー操作: 不要（自動選択）
```

### **現在の状態（問題）**
```
11月1日以降も
- タブ表示: 「概要」「8月」「9月」「10月」（変化なし）
- 選択タブ: 「10月」（古い月のまま）
- ユーザー操作: 手動クリックが必要
```

### **技術的な状況**
```
コンソールログ:
- rotationState: 'completed' ✅

- isSynced: true ✅

ブラウザ表示:
- タブ: 「概要」「8月」「9月」「10月」❌
- 選択: 「10月」❌
```

## 🔍 **根本原因の特定**

### **原因の数: 1つ**

**バックエンドAPI `/api/scheduler/rotation-status` が実装されていない**

### **証拠**

#### **1. APIテスト結果**
```
リクエスト: GET https://influberry.jp/api/scheduler/rotation-status
HTTPステータス: 200 OK
Content-Type: text/html; charset=utf-8
レスポンス内容: <!DOCTYPE html> (フロントエンドのindex.html)
```

#### **2. エラーログ**
```javascript
❌ APIエラー: SyntaxError: Unexpected token '<', "<!DOCTYPE "... is not valid JSON
```

#### **3. 問題の構造**
```
フロントエンド (monthlyRotation.js)
  ↓
  5分ごとにcheckRotationStatus()を実行
  ↓
  GET /api/scheduler/rotation-status
  ↓
バックエンド
  ↓
  ルートが存在しない
  ↓
  SPAフォールバック処理
  ↓
  index.htmlを返す (JSONではない)
  ↓
フロントエンド
  ↓
  JSONパースに失敗
  ↓
  lastRotationCheckが更新されない (10月23日のまま)
  ↓
  タブ生成ロジックが10月を基準に動作
  ↓
  タブ: 「概要」「8月」「9月」「10月」のまま
```

## 🔧 **根本解決策**

### **解決の方向性**
- 根本解決: バックエンドAPIを実装 ✅
- 暫定解決: フロントエンドで対応 ❌（推奨しない）

### **必要な実装**

#### **1. APIエンドポイント**
```
エンドポイント: /api/scheduler/rotation-status
メソッド: GET
認証: 必要（JWT）
```

#### **2. 期待されるレスポンス形式**
```json
{
  "success": true,
  "data": {
    "rotation_completed": true,
    "snapshot_exists": true,
    "last_rotation_date": "2025-11-01T00:00:00.000000",
    "current_month": 11,
    "current_year": 2025
  }
}
```

#### **3. フィールド仕様**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `success` | boolean | ✅ | API実行成功フラグ |
| `data.rotation_completed` | boolean | ✅ | 月次切り替えが完了しているか |
| `data.snapshot_exists` | boolean | ✅ | スナップショットが存在するか |
| `data.last_rotation_date` | string (ISO8601) | ✅ | 最後に月次切り替えを実行した日時 |
| `data.current_month` | integer | ✅ | 現在の月（1-12） |
| `data.current_year` | integer | ✅ | 現在の年 |

---

## 📝 **実装要件**

### **バックエンド実装が満たすべき条件**

1. **認証**
   - JWT認証が必要
   - `current_user_id`を取得

2. **データ取得**
   - ユーザーの最新のスナップショットを取得
   - スナップショットの日時を`last_rotation_date`として返す
   - スナップショットが存在しない場合は現在の日時を返す

3. **レスポンス**
   - 必ずJSON形式で返す
   - Content-Type: `application/json`
   - HTTPステータス: 200 (成功時)

4. **エラーハンドリング**
   - エラー時は以下の形式で返す
   ```json
   {
     "success": false,
     "error": "エラーメッセージ"
   }
   ```

## 📊 **既存コードとの整合性**

### **フロントエンドコードは変更不要**

`monthlyRotation.js`の`checkRotationStatus()`（305-338行目）は、バックエンドAPIが正しく実装されれば、そのまま動作します。

```javascript
// 既存コード（変更不要）
const response = await axios.get('/api/scheduler/rotation-status')

if (response.data.success) {
  const data = response.data.data
  
  if (data.rotation_completed && data.snapshot_exists) {
    this.setRotationState('completed')
    this.lastRotationCheck = data.last_rotation_date  // ←これが更新される
    
    await this.triggerTabRegeneration()
    await this.refreshFrontendData()
    
    return true
  }
}
```
