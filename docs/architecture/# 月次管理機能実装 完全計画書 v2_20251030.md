\#\# 1\. プロジェクト概要

\#\#\# 1.1 目的  
ユーザーが月次で案件管理の進捗を可視化し、目標設定と達成度評価を行える機能を実装する。

\#\#\# 1.2 目標とする効果  
\- \*\*安心感\*\*: "ちゃんと進んでる"の可視化  
\- \*\*達成感\*\*: "努力が可視化される"体験  
\- \*\*継続性\*\*: 興味増→定着→利用頻度増  
\- \*\*高速性\*\*: 本番環境で1秒以内の表示

\#\#\# 1.3 実装スコープ

\#\#\#\# ✅ 今回実装  
\- 月次目標設定機能（月別・可変）  
\- ステータス変更履歴記録（Project/Invoice）  
\- \*\*正負集計ロジック\*\*（ステータスの戻しを考慮）  
\- \*\*会計ロジック\*\*（発生主義に基づく集計）  
\- 月次集計API（高速化対応）  
\- タブ自動切替UI（月次変更時）  
\- プログレスバー表示（即座反映）

\#\#\#\# ❌ 今回対象外（次回フェーズ）

\#\#\# 1.5 絶対条件

| 条件 | 要求事項 |  
|------|---------|  
| \*\*パフォーマンス\*\* | 本番環境で月次セクション表示が1秒以内（ページ読み込み開始から表示完了まで） |

| \*\*数値保持\*\* | 月次自動切替後も、目標数値・達成数値は保持される |

\#\# 3\. 正負集計ロジックと会計ロジック

\#\#\# 3.1 正負集計ロジック（ステータス変更履歴による集計）

\#\#\#\# 原則  
\- \*\*正の変化\*\*: 目標に向かう変化（例: proposed → contracted \= \+1）  
\- \*\*負の変化\*\*: 目標から離れる変化（例: contracted → proposed \= \-1）  
\- \*\*最終数値\*\*: 正の変化 \- 負の変化

\#\#\#\# 1\. 獲得案件数の正負集計

\`\`\`python  
def calculate\_acquired\_projects(user\_id, year, month):  
    """  
    獲得案件数 \= (proposed→contracted の件数) \- (contracted→proposed の件数)  
    """  
    \# 正の変化（proposed → contracted: \+1）  
    positive\_changes \= db.session.query(  
        func.count(func.distinct(ProjectStatusHistory.project\_id))  
    ).join(Project).filter(  
        Project.user\_id \== user\_id,  
        ProjectStatusHistory.old\_status \== 'proposed',  
        ProjectStatusHistory.new\_status \== 'contracted',  
        extract('year', ProjectStatusHistory.changed\_at) \== year,  
        extract('month', ProjectStatusHistory.changed\_at) \== month  
    ).scalar() or 0  
      
    \# 負の変化（contracted → proposed: \-1）  
    negative\_changes \= db.session.query(  
        func.count(func.distinct(ProjectStatusHistory.project\_id))  
    ).join(Project).filter(  
        Project.user\_id \== user\_id,  
        ProjectStatusHistory.old\_status \== 'contracted',  
        ProjectStatusHistory.new\_status \== 'proposed',  
        extract('year', ProjectStatusHistory.changed\_at) \== year,  
        extract('month', ProjectStatusHistory.changed\_at) \== month  
    ).scalar() or 0  
      
    \# 最終的な獲得案件数  
    acquired\_projects \= positive\_changes \- negative\_changes  
    return acquired\_projects  
\`\`\`

\#\#\# 3.2 会計ロジック（請求書ステータス別の会計概念）

\#\#\#\# 請求書ステータス別の会計概念

| 項目 | 定義 | 含まれる請求書 | 金額の扱い | 備考 |  
|------|------|----------------|------------|------|  
| \*\*下書き（件数）\*\* | まだ正式に発行されていない請求書 | \`draft\` | \*\*会計上の金額に含めない\*\* | 未発行書類 |  
| \*\*キャンセル（件数）\*\* | 発行後に無効・取り消しになった請求書 | \`canceled\` | \*\*会計上の金額に含めない\*\* | 取消仕訳 |  
| \*\*送信済（件数・金額）\*\* | 顧客に正式送付した請求書（支払待ち） | \`sent\` | \*\*含める（売掛金発生）\*\* | AR発生中 |  
| \*\*支払済（件数・金額）\*\* | 入金が確認済みの請求書 | \`paid\` | \*\*含める（入金完了）\*\* | 売掛金消込済 |  
| \*\*期限超過（件数・金額）\*\* | 支払期日を過ぎても未入金 | \`overdue\` | \*\*含める（未収金額）\*\* | 債権管理用 |  
| \*\*未収金額\*\* | 請求済みだが未入金 | \`sent\` \+ \`overdue\` | \*\*含める\*\* | 売掛残高 |  
| \*\*総請求書金額\*\* | 発行済み請求書の合計 | \`sent\` \+ \`paid\` \+ \`overdue\` | \*\*含める\*\* | 下書き・キャンセル除外 |

\#\#\#\# 会計原則の厳守

\*\*✅ 含める\*\*: \`sent\`, \`paid\`, \`overdue\` ステータスの請求書    
\*\*❌ 含めない\*\*: \`draft\`, \`canceled\` ステータスの請求書

\#\#\#\# 送信済み請求書の正負集計

\`\`\`python  
def calculate\_sent\_invoices(user\_id, year, month):  
    """  
    送信済み金額 \= (draft→sent の金額) \- (sent→draft の金額)  
    ※ canceled は会計上含めない  
    """  
    \# 正の変化（draft → sent: \+金額）  
    positive\_sent \= db.session.query(  
        func.count(func.distinct(InvoiceStatusHistory.invoice\_id)),  
        func.sum(Invoice.total\_amount)  
    ).join(Invoice).filter(  
        Invoice.user\_id \== user\_id,  
        InvoiceStatusHistory.old\_status \== 'draft',  
        InvoiceStatusHistory.new\_status \== 'sent',  
        extract('year', InvoiceStatusHistory.changed\_at) \== year,  
        extract('month', InvoiceStatusHistory.changed\_at) \== month  
    ).first()  
      
    \# 負の変化（sent → draft: \-金額）  
    negative\_sent \= db.session.query(  
        func.count(func.distinct(InvoiceStatusHistory.invoice\_id)),  
        func.sum(Invoice.total\_amount)  
    ).join(Invoice).filter(  
        Invoice.user\_id \== user\_id,  
        InvoiceStatusHistory.old\_status \== 'sent',  
        InvoiceStatusHistory.new\_status \== 'draft',  
        extract('year', InvoiceStatusHistory.changed\_at) \== year,  
        extract('month', InvoiceStatusHistory.changed\_at) \== month  
    ).first()  
      
    \# キャンセルへの変更（sent/paid → canceled: \-金額）  
    canceled\_changes \= db.session.query(  
        func.count(func.distinct(InvoiceStatusHistory.invoice\_id)),  
        func.sum(Invoice.total\_amount)  
    ).join(Invoice).filter(  
        Invoice.user\_id \== user\_id,  
        InvoiceStatusHistory.old\_status.in\_(\['sent', 'paid'\]),  
        InvoiceStatusHistory.new\_status \== 'canceled',  
        extract('year', InvoiceStatusHistory.changed\_at) \== year,  
        extract('month', InvoiceStatusHistory.changed\_at) \== month  
    ).first()  
      
    sent\_count \= (positive\_sent\[0\] or 0\) \- (negative\_sent\[0\] or 0\) \- (canceled\_changes\[0\] or 0\)  
    sent\_amount \= float(positive\_sent\[1\] or 0\) \- float(negative\_sent\[1\] or 0\) \- float(canceled\_changes\[1\] or 0\)  
      
    return sent\_count, sent\_amount  
\`\`\`

\#\#\#\# 支払済み請求書の集計

\`\`\`python  
def calculate\_paid\_invoices(user\_id, year, month):  
    """  
    支払済み金額 \= payment\_date が当月の paid ステータス請求書  
    ※ 正負集計ではなく、最終ステータスで判定  
    """  
    paid\_result \= db.session.query(  
        func.count(Invoice.id),  
        func.sum(Invoice.total\_amount)  
    ).filter(  
        Invoice.user\_id \== user\_id,  
        Invoice.status \== 'paid',  
        Invoice.payment\_date.isnot(None),  
        extract('year', Invoice.payment\_date) \== year,  
        extract('month', Invoice.payment\_date) \== month  
    ).first()  
      
    paid\_count \= paid\_result\[0\] or 0  
    paid\_amount \= float(paid\_result\[1\] or 0\)  
      
    return paid\_count, paid\_amount  
\`\`\`

    year \= changed\_month.year

\#\#\# 6.2 月次自動切替ロジック

\#\#\#\# 仕様  
\- 日付が変わると（例: 11/1 00:00）、タブが自動更新  
\- 例: 10月31日 → \[8月\]\[9月\]\[10月\]  
\- 例: 11月1日 → \[9月\]\[10月\]\[11月\] (8月が消え、11月が追加)  
\- 目標数値・達成数値は保持される

\#\#\#\# 実装

\`\`\`javascript  
// stores/monthly.js  
import { defineStore } from 'pinia'  
import { ref, computed } from 'vue'

export const useMonthlyStore \= defineStore('monthly', () \=\> {  
  const currentDate \= ref(new Date())  
    
  // 自動更新: 1分ごとに日付をチェック  
  setInterval(() \=\> {  
    const now \= new Date()  
    if (now.getDate() \!== currentDate.value.getDate()) {  
      currentDate.value \= now  
      refreshTabs()  
    }  
  }, 60000\)  // 1分ごと  
    
  const displayMonths \= computed(() \=\> {  
    const now \= currentDate.value  
    const lastMonth \= new Date(now.getFullYear(), now.getMonth() \- 1, 1\)  
    const thisMonth \= new Date(now.getFullYear(), now.getMonth(), 1\)  
    const nextMonth \= new Date(now.getFullYear(), now.getMonth() \+ 1, 1\)  
      
    return \[  
      { id: formatMonth(lastMonth), label: getMonthLabel(lastMonth) },  
      { id: formatMonth(thisMonth), label: getMonthLabel(thisMonth) },  
      { id: formatMonth(nextMonth), label: getMonthLabel(nextMonth) }  
    \]  
  })  
    
  const defaultTab \= computed(() \=\> {  
    const now \= currentDate.value  
    return formatMonth(new Date(now.getFullYear(), now.getMonth(), 1))  
  })  
    
  function formatMonth(date) {  
    return \`${date.getFullYear()}-${String(date.getMonth() \+ 1).padStart(2, '0')}\`  
  }  
    
  function getMonthLabel(date) {  
    return \`${date.getMonth() \+ 1}月\`  
  }  
    
  async function refreshTabs() {  
    // タブ切替時も目標・実績データは保持  
    await fetchCurrentMonthlyData()  
  }  
    
  return {  
    displayMonths,  
    defaultTab,  
    refreshTabs  
  }  
})

\#\#\#\# monthlyStore.js（完全版）

\`\`\`javascript  
import { defineStore } from 'pinia'  
import { ref, computed } from 'vue'  
import axios from 'axios'

export const useMonthlyStore \= defineStore('monthly', () \=\> {  
  // State  
  const currentDate \= ref(new Date())  
  const targets \= ref({})  // { '2025-10-01': { projects: 5, income: 200000 } }  
  const stats \= ref({})    // { '2025-10-01': { acquired: 3, ... } }  
  const loading \= ref(false)  
  const error \= ref(null)  
    
  // Computed  
  const displayMonths \= computed(() \=\> {  
    const now \= currentDate.value  
    const lastMonth \= new Date(now.getFullYear(), now.getMonth() \- 1, 1\)  
    const thisMonth \= new Date(now.getFullYear(), now.getMonth(), 1\)  
    const nextMonth \= new Date(now.getFullYear(), now.getMonth() \+ 1, 1\)  
      
    return \[  
      { id: formatMonth(lastMonth), label: getMonthLabel(lastMonth) },  
      { id: formatMonth(thisMonth), label: getMonthLabel(thisMonth) },  
      { id: formatMonth(nextMonth), label: getMonthLabel(nextMonth) }  
    \]  
  })  
    
  const defaultTab \= computed(() \=\> {  
    const now \= currentDate.value  
    return formatMonth(new Date(now.getFullYear(), now.getMonth(), 1))  
  })  
    
  // Actions  
  async function fetchCurrentMonthlyData() {  
    loading.value \= true  
    error.value \= null  
      
    try {  
      // 並列取得（高速化）  
      const \[targetsRes, statsRes\] \= await Promise.all(\[  
        axios.get('/api/monthly-targets/current'),  
        axios.get('/api/monthly-stats/current')  
      \])  
        
      // 目標データ格納  
      targetsRes.data.data.forEach(target \=\> {  
        targets.value\[target.target\_month\] \= target  
      })  
        
      // 統計データ格納  
      statsRes.data.data.forEach(stat \=\> {  
        stats.value\[stat.month\] \= stat  
      })  
    } catch (err) {  
      error.value \= err.message  
    } finally {  
      loading.value \= false  
    }  
  }  
    
  async function saveTarget(targetMonth, data) {  
    try {  
      const response \= await axios.post('/api/monthly-targets', {  
        target\_month: targetMonth,  
        ...data  
      })  
        
      // 保存後、即座にstateを更新  
      targets.value\[targetMonth\] \= response.data.data  
        
      return { success: true }  
    } catch (err) {  
      return { success: false, error: err.message }  
    }  
  }  
    
  // Utility  
  function formatMonth(date) {  
    return \`${date.getFullYear()}-${String(date.getMonth() \+ 1).padStart(2, '0')}-01\`  
  }  
    
  function getMonthLabel(date) {  
    return \`${date.getMonth() \+ 1}月\`  
  }  
    
  // 日付自動更新  
  setInterval(() \=\> {  
    const now \= new Date()  
    if (now.getDate() \!== currentDate.value.getDate()) {  
      currentDate.value \= now  
      fetchCurrentMonthlyData()  
    }  
  }, 60000\)  
    
  return {  
    currentDate,  
    targets,  
    stats,  
    loading,  
    error,  
    displayMonths,  
    defaultTab,  
    fetchCurrentMonthlyData,  
    saveTarget  
  }  
})

\#\# 📊 月次セクション表示遅延対策のヒント

\#\#\# 改善アイデア①: 「目標×月次履歴」の分離

\#\#\#\# 現状の問題点  
毎回全履歴（概要+8月+9月+10月...）をAPIで返している  
→ 履歴は別APIに分ける

\#\#\#\# 改善策  
\`\`\`  
/api/monthly/current  → 今月+先月+次月だけ（軽量）  
/api/monthly/history  → ユーザーが「過去を見る」を押した時のみロード  
\`\`\`

\*\*効果\*\*: 体感速度が2〜4倍改善

\#\#\# 改善アイデア②: バックエンドの遅延削減

\#\#\#\# よくある遅延ポイント  
\- SQLAlchemyで複数クエリが発生  
\- 履歴を集計してから返している（ループ内SELECT）  
\- datetime処理やJSON変換に時間がかかっている

\#\#\#\# 対応策: 事前集計テーブル（monthly\_summary）  
\`\`\`python  
\# Flask側（高速化）  
@app.route("/api/monthly/\<int:year\>/\<int:month\>")  
def get\_monthly\_summary(year, month):  
    summary \= MonthlySummary.query.filter\_by(  
        user\_id=current\_user.id,  
        year=year,  
        month=month  
    ).first()  
    return jsonify(summary.to\_dict())  
\`\`\`

\*\*効果\*\*: DB読み取りが10〜50倍高速化
