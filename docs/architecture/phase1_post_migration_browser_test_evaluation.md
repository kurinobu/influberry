## 3. タブ切り替えの問題の詳細分析（🔴 新規発見・残存問題）

### 3.1 問題の詳細

**ユーザー報告**:
> 表示が最終的に当月タブが表示されてましたが、現在は先月タブが表示されて停止します。

**コンソールログより**:

1. **初期化時のタブ選択**:
   ```
   🔧 初期化: 月次切り替え状態を確認
   {rotationState: 'idle', lastRotationCheck: null, currentYear: 2025, currentMonth: 11, currentMonthId: '2025-11'}
   📅 現在月を初期値に設定: 2025-11
   ```

2. **当月タブ（2025-11）が選択される**:
   ```
   🔧 Phase 2: currentMonthTabの変更を検知 {newTab: '2025-11', oldTab: 'overview'}
   🎉 Phase 2: 新しい月のタブが選択されました {selectedTab: '2025-11', previousTab: 'overview'}
   ```

3. **月次切り替え状態の変更**:
   ```
   月次切り替え状態変更を検知: {newState: 'completed', oldState: 'idle'}
   月次切り替えが検知されました。
   ```

4. **現在日時とlastRotationCheckの不一致**:
   ```
   ⚠️ 現在日時とlastRotationCheckが不一致 - 現在月を優先
   {currentMonthId: '2025-11', lastMonthId: '2025-10'}
   ```

5. **先月タブ（2025-10）に切り替わる**:
   ```
   🔧 Phase 2: currentMonthTabの変更を検知 {newTab: '2025-10', oldTab: '2025-11'}
   🎉 Phase 2: 新しい月のタブが選択されました {selectedTab: '2025-10', previousTab: '2025-11'}
   ```

6. **先月タブ（2025-10）で停止**:
   - その後、タブが切り替わらず、先月タブ（2025-10）が表示されたまま

### 3.2 根本原因の分析

#### 原因1: 月次切り替え状態の変更タイミング

**問題の流れ**:
1. 初期化時: `rotationState: 'idle'`, `lastRotationCheck: null`
2. 初期化後: 現在月（2025-11）が選択される
3. 月次切り替え状態の変更: `rotationState: 'idle'` → `'completed'`
4. `lastRotationCheck`が更新される: `'2025-10-01T00:00:00'`
5. タブ切り替えロジックが実行され、先月タブ（2025-10）に切り替わる

**問題点**:
- 月次切り替え状態の変更が初期化後に発生している
- `lastRotationCheck`が古い値（10月1日）のまま
- 現在日時（11月1日）と`lastRotationCheck`が不一致のため、タブ切り替えロジックが実行される

#### 原因2: タブ切り替えロジックの競合

**問題の詳細**:
- 初期化時に現在月（2025-11）を優先するロジックが実行される
- しかし、月次切り替え状態の変更後に、`lastRotationCheck`に基づくロジックが実行される
- 結果として、先月タブ（2025-10）に切り替わり、その後切り替わらない

**影響範囲**:
- `DashboardPage.vue`の初期化処理
- `MonthlyTabs.vue`のタブ生成ロジック
- `monthlyRotation.js`の月次切り替え監視

### 3.3 影響度評価

- **影響度**: 🔴 **高い**（ユーザー体験への大きな影響）
- **優先度**: **高**（Phase 1の修正とは別問題だが、緊急対応が必要）

**評価**: 🔴 **残存問題として記録が必要**
