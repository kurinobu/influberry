### 1.2 修正内容

#### 修正1: 認証方式の統一（根本解決）

**変更前**:
```python
from flask_jwt_extended import jwt_required, get_jwt_identity

@monthly_current_bp.route('/api/monthly/current', methods=['GET'])
@jwt_required()
def get_current_monthly_data():
    try:
        user_id = get_jwt_identity()
```

**変更後**:
```python
from flask_login import login_required, current_user

@monthly_current_bp.route('/api/monthly/current', methods=['GET'])
@login_required
def get_current_monthly_data():
    try:
        user_id = current_user.id
```

**変更理由**:
- 既存API (`monthly.py`, `monthly_stats.py`) と認証方式を統一
- Flask-Loginのセッション認証を使用（フロントエンドと一致）
- 根本解決: 認証エラーを根本的に解消

- **具体的**: `@jwt_required()` → `@login_required` という具体的な変更
- **一般化を回避**: 抽象的な認証ラッパーを作成しない
