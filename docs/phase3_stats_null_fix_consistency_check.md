## 1. 修正内容のサマリー

### 1.1 修正対象
- **問題**: `stats: null`問題（`fetchCurrentMonthlyData()`後のデータ取得で`null`が返される）
- **発生箇所**: `MonthlyStatsSection.vue`の`loadData()`と`onMounted`
- **原因**: 非同期処理のタイミング問題（Vueのリアクティブ更新が完了する前に`getStatsByMonth()`が呼ばれる）

### 1.2 修正内容

#### ✅ **frontend/src/components/MonthlyStatsSection.vue**
1. **nextTick()の追加（loadData()内）**
   - `fetchCurrentMonthlyData()`後に`nextTick()`を追加
   - Vueのリアクティブ更新を確実に待つ

2. **nextTick()の追加（onMounted内）**
   - 初期化時の`fetchCurrentMonthlyData()`後にも`nextTick()`を追加

3. **デバッグログの追加**
   - `fetchCurrentMonthlyData()`後の`getStatsByMonth()`呼び出し結果をログ出力
   - `allStatsKeys`を追加してデバッグを容易に

#### ✅ **frontend/src/stores/monthly.js**
1. **デバッグログの追加**
   - `fetchCurrentMonthlyData()`内でstats設定完了をログ出力
   - データ取得完了時の詳細情報をログ出力

### 1.3 修正ファイル
- `frontend/src/components/MonthlyStatsSection.vue`
- `frontend/src/stores/monthly.js`
