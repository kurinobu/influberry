## 2. Phase 3実装内容の確認

### 2.1 実装済み項目

#### ✅ **Step 3-1: スケルトン表示時間の最適化**
1. **不要な`watch`の削除**（根本解決）
   - `watch(() => projectsStore.projects, { deep: true })`を削除
   - `watch(() => invoicesStore.invoices, { deep: true })`を削除
   - 理由: 月次統計は履歴ベースで計算され、ステータス変更時にバックエンドで自動更新されるため

2. **ローディング状態管理の統一**（シンプル構造 > 複雑構造）
   - ローカル`loading`（`ref(false)`）を削除
   - ストア`loading`（`monthlyStore.loading`）のみを使用
   - テンプレート内の`v-if="!loading"`を`v-if="!monthlyStore.loading"`に変更

3. **データ取得タイミングの最適化**（統一・同一化 > 特殊独自）
   - 新API (`/api/monthly/current`) の使用を徹底
   - 初期化時にデータが取得済みか確認し、必要時のみAPI呼び出し
   - `loadData()`で既存データから取得を試み、データがない場合のみAPI呼び出し（フォールバック）
