## 1. 修正内容のサマリー

### 1.1 修正対象
- **問題**: `stats: null`問題（競合状態による発生）
- **発生箇所**: `fetchStats()`と`fetchCurrentMonthlyData()`の競合状態
- **原因**: `fetchStats()`実行中に`fetchCurrentMonthlyData()`が呼び出され、`fetchCurrentMonthlyData()`完了後、`fetchStats()`が完了してstatsを上書き

### 1.2 修正内容

#### ✅ **frontend/src/stores/monthly.js**
1. **`fetchingCurrentMonthlyData`フラグの追加**
   - `fetchCurrentMonthlyData()`実行中フラグを追加
   - 競合状態を検知・防止するために使用

2. **`fetchCurrentMonthlyData()`内での競合状態防止**
   - 実行中の`fetchStats()`を完了待ち（最大5秒）
   - `fetchCurrentMonthlyData`実行中フラグを設定

3. **`fetchStats()`内での競合状態防止**
   - `fetchCurrentMonthlyData`実行中はstatsを上書きしない
   - データがない場合のみ設定

4. **`reset()`内でのフラグリセット**
   - `fetchingCurrentMonthlyData`フラグもリセット

### 1.3 修正ファイル
- `frontend/src/stores/monthly.js`
