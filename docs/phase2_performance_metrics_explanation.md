## 1. LCP（Largest Contentful Paint）について

### 1.1 LCPとは

**LCP（Largest Contentful Paint）**は、**最大のコンテンツが表示されるまでの時間**を測定するWebパフォーマンス指標です。

- **意味**: ユーザーがページの「メインコンテンツ」を見ることができるまでの時間
- **単位**: 秒（s）またはミリ秒（ms）
- **測定対象**: ページ内で最も大きなコンテンツ要素（画像、動画、テキストブロックなど）

### 1.2 LCPの評価基準

| LCPの値 | 評価 | 説明 |
|---------|------|------|
| **< 2.5秒** | ✅ **Good（良い）** | 良好なユーザー体験 |
| **2.5秒 - 4.0秒** | ⚠️ **Needs Improvement（要改善）** | 改善の余地あり |
| **> 4.0秒** | ❌ **Poor（悪い）** | ユーザー体験が悪い |

### 1.3 あなたの結果

```
Largest Contentful Paint (LCP): 2.03 s
Your local LCP value of 2.03 s is good.
```

**評価**: ✅ **Good（良い）**

**説明**: 
- LCPが2.03秒は「Good」の範囲内（< 2.5秒）
- ユーザー体験の観点からは良好
- ただし、計画書v2.0の目標（1秒以内）との比較では要改善

## 2. パフォーマンス指標の種類

### 2.1 Core Web Vitals（主要なWebパフォーマンス指標）

Chrome開発者ツールのPerformanceタブでは、以下の指標が確認できます：

#### 1. LCP（Largest Contentful Paint）
- **測定内容**: 最大のコンテンツが表示されるまでの時間
- **目標**: < 2.5秒（Good）
- **あなたの結果**: 2.03秒 ✅

#### 2. FID（First Input Delay）
- **測定内容**: ユーザーが最初にインタラクション（クリック、タップなど）をしたときの応答時間
- **目標**: < 100ms（Good）

#### 3. CLS（Cumulative Layout Shift）
- **測定内容**: ページのレイアウトがどれだけずれるか（視覚的な安定性）
- **目標**: < 0.1（Good）

### 2.2 その他の重要な指標

#### 1. DOMContentLoaded（DOM読み込み完了時間）
- **測定内容**: HTMLの解析とDOM構築が完了するまでの時間
- **目標**: < 1秒（理想）

#### 2. Load（ページ読み込み完了時間）
- **測定内容**: すべてのリソース（画像、CSS、JavaScriptなど）が読み込まれるまでの時間
- **目標**: < 1秒（計画書v2.0の目標）

#### 3. TTFB（Time To First Byte）
- **測定内容**: サーバーが最初のバイトを返すまでの時間（サーバー応答時間）
- **目標**: < 200ms（Good）

## 4. 改善方法

### 4.1 LCPの改善（2.03秒 → 1秒以内）

#### 方法1: 画像の最適化
- **目的**: 画像の読み込み時間を短縮
- **方法**:
  - 画像の圧縮（WebP形式の使用）
  - 遅延読み込み（Lazy Loading）
  - 画像のサイズ最適化

#### 方法2: APIレスポンス時間の短縮
- **目的**: データ取得時間を短縮
- **方法**:
  - 新API (`/api/monthly/current`) の最適化（既に実装済み）
  - 事前集計テーブル（`monthly_summary`）の活用（Phase 3で実装予定）
  - キャッシュの活用（Phase 1で実装済み）

#### 方法3: JavaScriptの最適化
- **目的**: JavaScriptの実行時間を短縮
- **方法**:
  - コード分割（Code Splitting）
  - 不要なJavaScriptの削除
  - 非同期読み込みの活用

#### 方法4: CSSの最適化
- **目的**: CSSの読み込み時間を短縮
- **方法**:
  - クリティカルCSSのインライン化
  - 不要なCSSの削除
  - CSSの圧縮
