## 4. 問題の原因分析（更新）

### 4.1 スケルトン表示時間の遅延の原因

#### **原因1: 複数回のAPI呼び出し**
- 月次切り替え状態のチェック時にAPI呼び出し
- タブ変更時にAPI呼び出し
- データ同期時にAPI呼び出し
- 各API呼び出しが完了するまで`loading`が`true`のまま

#### **原因2: ローディング状態管理の問題**
- `MonthlyStatsSection.vue`の`loading`状態が適切に管理されていない
- 複数のAPI呼び出しの完了状態を適切に追跡できていない
- 最初のAPI呼び出しが完了してもスケルトンが非表示にならない

#### **原因3: データ取得タイミングの問題**
- データ取得が複数のタイミングで発生している
- 各データ取得が完了するまでスケルトンが表示され続けている

### 4.2 重複API呼び出しの原因

#### **原因1: 月次切り替え状態のチェック**
- 月次切り替え状態のチェック時にAPI呼び出し
- タブ変更時にもAPI呼び出し
- データ同期時にもAPI呼び出し

#### **原因2: 重複防止ロジックの不十分**
- 重複防止ロジックが実装されているが、適切に機能していない可能性
- 複数のトリガーが同時に発生している
