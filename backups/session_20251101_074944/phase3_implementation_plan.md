#### 🔴 **月次タブ自動切り替え問題（新規発見・2025年11月1日）**

**問題内容**:
> 現在11月1日になったが、月次タブが自動で切り替わっていない。アクセス時に一瞬だけ切り替わるが、元に戻って当月タブは10月表示に戻る問題。

**問題の流れ**:
1. アクセス時に11月タブに一瞬切り替わる
2. 初期化処理やwatchにより、10月タブに戻る
3. 最終的に10月タブが表示される（現在は11月1日なのに）

**根本原因**（コンソールログ分析）:
1. **`lastRotationCheck`が古い日時を使用**
   - コンソールログ: `lastRotationCheck: '2025-10-25T08:54:54.500659'`
   - 現在は11月1日だが、10月25日の日時が使用されている
   - タブ生成ロジックが`lastRotationCheck`を基準にしているため、10月タブが生成される
2. **現在日時と`lastRotationCheck`の不一致**
   - `generateDynamicTabs()`内で`lastRotationCheck`を基準にタブを生成
   - `initializeCurrentMonthTab()`でも`lastRotationCheck`を基準にタブを選択
   - 現在日時（11月1日）と`lastRotationCheck`（10月25日）が不一致
3. **月次切り替えが実際に完了していない可能性**
   - バックエンドで月次切り替えが実行されていない可能性
   - `rotationState: 'completed'`だが、`lastRotationCheck`が古い

**影響度**: 🔴 極めて高い（ユーザー体験への大きな影響、機能の誤動作）
**優先度**: 最高（緊急対応が必要）

**推奨される修正案**:
1. **最優先**: `lastRotationCheck`の更新確認
   - バックエンドで月次切り替えが正しく実行されているか確認
   - `checkRotationStatus()`の動作確認
2. **高優先**: 現在日時と`lastRotationCheck`の不一致時の処理
   - 現在日時を基準にしたタブ生成ロジックの追加
   - `lastRotationCheck`が古い場合のフォールバック処理
3. **中優先**: 初期化処理の見直し
   - `initializeCurrentMonthTab()`で現在日時も考慮
   - タブ切り替え時の競合状態の解消

#### ℹ️ **Vueビルド設定の警告（非機能影響）**
- **警告内容**: `Component provided template option but runtime compilation is not supported`
- **影響度**: なし（機能には影響なし、動作は正常）

#### **2-3-2: watch(() => props.currentTab)の修正（高優先）**

**問題点**:
1. キャッシュがある場合でも、`debouncedLoadData()`が実行される可能性がある
2. `watch`が複数回トリガーされている可能性がある

**実装内容**:
1. `lastProcessedTab`を使用して重複処理を防止
2. キャッシュがある場合は、`debouncedLoadData()`を実行しない
3. 既存のタイマーをクリア

**実装場所**:
- `frontend/src/components/MonthlyStatsSection.vue`（行354-395）

**修正案**:
```javascript
let debounceTimer = null
let lastProcessedTab = null // 最後に処理したタブを記録

watch(() => props.currentTab, (newTab) => {
  // 同じタブが既に処理済みの場合はスキップ
  if (lastProcessedTab === newTab) {
    return
  }
  
  // リスク対策: キャッシュがある場合は即座に表示
  if (newTab === 'overview') {
    if (monthlyStore.overview) {
      overviewData.value = monthlyStore.overview
      lastProcessedTab = newTab
      return // debounceをバイパス
    }
  } else {
    const monthKey = newTab + '-01'
    const cachedStats = monthlyStore.getStatsByMonth(monthKey)
    if (cachedStats) {
      stats.value = cachedStats
      lastProcessedTab = newTab
      return // debounceをバイパス
    }
  }
  
  // データが存在しない場合のみdebounce後にAPI呼び出し
  // 既存のタイマーをクリア
  if (debounceTimer) {
    clearTimeout(debounceTimer)
  }
  
  lastProcessedTab = newTab
  debounceTimer = setTimeout(async () => {
    await loadData()
    debounceTimer = null
  }, 50)
})
```
