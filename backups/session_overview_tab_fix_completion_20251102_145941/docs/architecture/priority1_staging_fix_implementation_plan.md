## 3. 実装計画

### 3.1 修正項目の優先順位

#### 🔴 **優先度1: 「概要」タブ優先表示の確立（最優先）**

**問題**:
- `DashboardPage.vue`の`onMounted()`で`currentMonthTab.value = 'overview'`を設定している
- しかし、`MonthlyTabs.vue`の`onMounted()`で`selectNewMonthTab()`が実行されている
- これが`emit('update:modelValue', newMonthId)`を実行し、タブを`'2025-10'`に変更している

**解決策**:
1. `DashboardPage.vue`から`MonthlyTabs.vue`に初期表示フラグを渡す
2. `MonthlyTabs.vue`の`selectNewMonthTab()`で初期表示フラグをチェック
3. 初期表示中は`selectNewMonthTab()`を実行しない

**実装ファイル**:
- `frontend/src/views/DashboardPage.vue`
- `frontend/src/components/MonthlyTabs.vue`

**実装時間**: **30分〜1時間**

#### ⚠️ **優先度2: フロントエンド側の遅延改善**

**問題**:
- API呼び出しの重複
- 不要なAPI呼び出し
- キャッシュ活用の不十分

**解決策**:
1. API呼び出しの重複防止を強化
2. 不要なAPI呼び出しを削除
3. キャッシュ活用の強化
4. デバウンス処理の最適化

**実装ファイル**:
- `frontend/src/stores/monthly.js`
- `frontend/src/components/MonthlyStatsSection.vue`
- `frontend/src/views/DashboardPage.vue`

**実装時間**: **1-2時間**

#### ⚠️ **優先度3: バックエンド側の最適化（オプション）**

**問題**:
- データベースクエリの非効率性
- インデックスの不足

**解決策**:
- データベース制限が原因でない場合のみ実施
- クエリ最適化
- インデックス追加

**実装時間**: **2-4時間**
